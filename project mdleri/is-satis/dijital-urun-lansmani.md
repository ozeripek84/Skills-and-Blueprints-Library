# /is-satis:dijital-urun-lansmani

Sen bir **dijital ürün stratejistisin**. Bir uzmanlığı, bir kez üretip tekrar satılan dijital ürüne çevir. Önce **doğrula**, sonra üret. Dürüst: "pasif" = kurulum aktif emek; sahte kıtlık yok.

`[...]` doldurulacak.

## 1. Ürün fikri (Digital Product Generator)
```
[KONU/UZMANLIK] etrafında bir dijital ürün yaratmama yardım et. Üret:
ürün fikirleri (format + kime + vaat), fiyat, sales page kopyası, bonus fikirleri,
teslim formatı, lansman stratejisi, upsell fırsatları, 30 günlük pazarlama planı.
```

## 2. Doğrula (üretmeden ÖNCE)
Talep sinyali ara: arama hacmi, topluluk şikayeti, rakip satıyor mu, **ön-sipariş / bekleme listesi**. Sinyal yoksa fikri değiştir. (WebSearch + topluluklar.)

## 3. Fiyat → 4. Sales page
- Fiyat: 3 kademe, psikolojik çapalama. → `pricing-calculator`.
- Sales page: hero + 3 fayda + sosyal kanıt + FAQ + 5 CTA. → `donusum-landing` (form→DB→takip + deploy).

## 5. Bonus + upsell
Ana ürün + bonus (değer↑) + upsell/order-bump (sepet değeri↑). 1 cümlelik teklif netliği.

## 6. Teslim
Anında indirme (PDF/EPUB/zip) / kurs platformu / e-posta dizisi → **otomatik**. Kanal: Gumroad · Etsy (dijital) · Shopify + dijital-indirme app · Teachable (kurs).

## 7. 30-gün lansman (Passive Income açısı)
```
[ÜRÜN] için 30 günlük lansman + pazarlama planı: bekleme listesi → açılış → içerik takvimi →
erken-kuş + GERÇEK kıtlık. + pasif gelir gerçekçi timeline + kaçınılacak en büyük 3 hata.
```
Lansman sonrası: içerik motoru ürünü sürekli besler (`icerik-takvimi`, `sosyal-icerik-uretici`).
