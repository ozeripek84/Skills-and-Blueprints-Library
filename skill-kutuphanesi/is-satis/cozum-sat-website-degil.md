# Website Değil Çözüm Sat (niş özel yazılım)

## Ne zaman
Küçük/yerel işletmelere değer satarken — ama "daha güzel website" satışı işe yaramıyorsa. Onun yerine **işletmeye para kazandıran / hayatını kolaylaştıran özel sistem** sat.

## Temel içgörü
**Kimse website istemiyor.** Website kartvizit gibidir — orada öylece durur, sahibi düşünmez. Daha güzel site teklif edince "kimin umurunda, işim zaten yürüyor" derler. Asıl istedikleri: **daha çok para + daha az dert.** O yüzden çözümü/sistemi sat, siteyi değil.

## Yöntem
1. **Niş seç + acı noktası bul.** Tek bir spesifik problemi çöz; sonra benzer işletmelere kopyala. Sahibin yerine kendini koy: günü nasıl geçiyor, neyi zor? Bilinen boşlukları araştır.
2. **Niş freebie (hazır fırsat):** **düzensiz rezervasyonlu** işletmeler — abonelik kuramıyorlar ama düzenli ihtiyaç var: köpek kuaförü, personal trainer, berber, estetisyen. Burada büyük yazılım yok → boşluk.
3. **Claude Code ile niş özel yazılım kur** — büyük "herkese-uyan" yazılımın (HubSpot $800/ay) yapamadığı, **tam o işe özel** sistem: booking + otomatik hatırlatma, mini-CRM, compliance/dosya takibi, "presentation mode", kurs modülü. Fazladan buton yok, tam ihtiyaç kadar.
4. **Pitch = problem listesi + çözüm.** "Sende şu 1-2-3-4-5 sorun var; bunları çözen bir sistem yaptım." Gerekirse **demo/dummy versiyon** önce yap, paylaş. (Güzel site + SEO da çözümün parçası olabilir ama ana vaat değil.)
5. **Abonelik modeli.** Aylık ücret (~$250/ay). Araç, maliyetinden **fazla** kazandırıyorsa müşteri asla iptal etmez. Yeni alan/özellik isterse → "ekledim" (büyük yazılımda "desteklenmiyor").

## Örnekler (videodan)
- **Silah eğitimi:** öğrenciye otomatik "bir sonraki dersi/seviyeyi book et" + doğum günü/tatil hatırlatması → daha çok ders = para.
- **Gelinlik butiği:** randevu + mini-CRM + "pick dresses" + **presentation mode** ("Welcome Olivia" dev ekranda, paylaşılabilir, hover'da kıyafet klibi) → butik deneyimi özel → daha çok satış.
- **Güvenlik görevlisi lisans yenileme:** yenileme tarihi + belge + compliance takibi (HubSpot yerine birebir özel CRM).

## Çıktı standardı
- Önce **acı noktası**, sonra çözüm. Tek niş, tekrarlanabilir.
- Yazılım maliyetinden fazla kazandırır (ROI net) → düşük churn.
- Tam ihtiyaç kadar, fazlalık yok (Karpathy: sadelik).

## Yaygın hatalar
- "Daha güzel website" satmaya çalışmak (dönüşmez).
- Generalist olmak — niş + spesifik problem yok.
- ROI'yi göstermemek (neden ödesin?).
- Aşırı-mühendislik (gereksiz özellik).
