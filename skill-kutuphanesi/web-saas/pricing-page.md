# Pricing Page

## Ne zaman
SaaS/hizmet için satış-conversion'a optimize fiyat sayfası.

## Stack
Next.js + Tailwind + shadcn

## Süreç
1. 3 tier (Free / Pro / Business)
2. Aylık/yıllık toggle (yıllıkta %20 indirim göster)
3. Most popular badge ortadakine
4. Feature comparison table
5. FAQ (10 soru)
6. Money-back guarantee
7. Footer'da "büyük şirket misin? sales ile konuş"

## Çıktı standardı
- Mobile'da tier'lar stack
- Annual toggle smooth animation
- Each plan'in CTA buton'u net
- Trust badges (Stripe, money-back)

## Yaygın hatalar
- 5+ tier (felç)
- "Custom" plan'i Pro'dan ucuz yapmak
- Hidden fee (KDV vs)
