# Landing Page Builder

## Ne zaman
Ürün/hizmet için satış odaklı tek sayfa.

## Stack
Next.js + Tailwind + shadcn + Framer Motion

## Süreç
1. Hero (clear value prop + CTA)
2. Social proof (logos / testimonials)
3. Features (3-6, alternating image+text)
4. How it works (3 adımda)
5. Pricing (3 plan)
6. FAQ (8 soru)
7. Final CTA + Footer

## Çıktı standardı
- Lighthouse 90+ (mobile)
- Türkçe meta tags
- Open Graph image
- Form: react-hook-form + zod
- Animasyonlar smooth, abartısız

## Yaygın hatalar
- Lorem ipsum bırakmak
- Stock görsel kullanmak (Unsplash daha iyi)
- 5 farklı font (max 2 kullan)
