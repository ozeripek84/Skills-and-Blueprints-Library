# Three.js Fluid Reveal Portfolio

A dark editorial portfolio with a **Three.js cursor trail** that reveals
a second portrait beneath the first one. Move your mouse — wherever you
draw, the image underneath shows through.

Built live on YouTube with **Claude**.

---

## Quick start

```bash
git clone https://github.com/YildizDikme/threejs-fluid-reveal-portfolio.git
cd threejs-fluid-reveal-portfolio
npm install
npm run dev
